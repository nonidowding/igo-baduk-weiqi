# Basic/Capture Level 2
## New Rules
To take capture go to the next level and make it more difficult, change the objective. All of the previous rules are still in effect except now you must capture at least 3 stones to win. This means first capture does not necessarily win. If you only capture 1 or 2 stones play continues. 

I suggest playing with this rule set on a 9x9 board.
